# Tong hop cac kien thuc 
## 1. Tong hop kien thuc ve Javascript
    ### khai bao bien 
        Let [ten_bien]="gia tri"
    ### khai bao hang 
        const [ten_hang]="gia tri"
    ### kieu du lieu number 
        + so nguyen 
          const age =25;
        + so thuc
          const price=2000;
        + so vo han 
        const indinify=Indinify;
        + khong phai la so 
        const notNumber=NaN;
    ### chuoi ki tu string
      constr name ="nguyen truong"
    ### boolean ( gia tri ve logic)
       constr isActive=true;
       constr isActive=false;
    ### Toan tu so sanh : dung de so sanh 2 toan hang
       so sanh bang : == va ===
       so sanh khong bang : !=
       so sanh lon hon, nho hon : >,<,>=,<=
    ### Toan tu logic : AND , OR
      AND ( &&): tra ve TRUE neu ca 2 dieu kien cung dung
      OR (||): tra ve TRUE neu 1 trong 2 dieu kien dung
    ### Toan tu 1 ngoi
      **Prefix:** toan tu nam o phia truoc (tang truoc tra ve sau )
       ++i
       --i
      **Postfix:** toan tu nam o phia sau (tra ve truoc roi tang sau)
       i++
       i--
    ### Toan tu toan hoc
      tuong tu nhu cac phep tinh +,-,*./ da duoc hoc
    ### Cau dieu kien
       if(<dieu kien>){
        //code
       }
    ### Vong lap
      cu phap vong lap for
      for (dieu kien khoi tao; dieu kien lap; cap nhat)
      {
        //code
      }
## 2. Tong hop kien thuc ve GIT
 -  **git init**: khởi tạo 1 project 
 - **git add <file name>**: đưa 1 file cụ thể vào vùng staging area
 - **git add .** : Đưa tất cả file thay đổi vào vùng staging area
 - **git commit -m "message"**: Lưu lại những gì đã ở staging area thành 1 commit
 - **git push origin main ** : cau lenh push code len git
