## 1. GIT
1, git clone : là hành động lấy code từ 1 repo đã có sẵn về máy cá nhân 
câu lệnh: git clone <link repo>
- nếu muốn đặt lại tên cho repo thì dùng cú pháp git clone <link repo><tên mới>
2, git push : đưa code từ vùng repository ở local của 1 nhánh cụ thể lên remote
 câu lệnh: git push <remote name><branch name>
 3, git pull : là hành động lấy code từ 1 nhánh về local
 câu lệnh : git pull  <remote name><branch name>
 ## 2. Xpath
 - parent: là node phía trên trực tiếp của node hiện tại 
 - child : là node phía dưới của node hiện tại 
 - ancestor: là các node cha ở phía trên 
 - descendent: ( hậu duệ) là các node nằm bên trong mình 
 - following: là tất cả các phần tử phía sau
 - preceding: là tất cả các phần tử phía trước
 - following-cebling: là tất cả anh em phía sau cùng cấp
 - preceding-cebling : là tất cả anh em phía trước cùng cấp
